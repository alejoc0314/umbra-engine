# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trato respetuoso, crítica al trabajo y no a las personas, y cero tolerancia al
acoso. Para reportar un comportamiento inaceptable, escribe a quien mantiene el proyecto por el
reporte privado de GitHub (ver [`SECURITY.md`](SECURITY.md)); se atiende con confidencialidad.
